# PokerHub 初级 Demo

两个玩法：

- **抽牌比点**：双人各出一张比大小，先到 3 分赢。
- **斗地主**：一副 54 张，三个人打，叫分定地主，谁先出完手牌谁赢。

不登录就能和机器人打。注册后可以改牌组、匹配朋友、留下历史。

胜负只由服务器计算。网页只负责按钮和展示。

## 依赖

Python 3.11 及以上。

```bash
pip install -r requirements.txt
```

| 包 | 用途 |
| --- | --- |
| fastapi | 网页和接口 |
| uvicorn | 启动服务 |
| websockets | 浏览器对战连接，不能省略 |
| sqlalchemy | 用户、牌组和历史 |
| pydantic | 检查请求数据 |
| httpx | 只在运行自检时用到 |

## 启动

```bash
python -m backend.main
```

浏览器打开 http://127.0.0.1:8000 。点「开始游戏」打抽牌比点，点「斗地主人机」打斗地主。

自检（可选）：

```bash
python -m backend.demo       # 比点规则引擎
python -m backend.smoke      # 比点接口和 WebSocket
python -m backend.ddz_demo   # 斗地主规则引擎
python -m backend.ddz_smoke  # 斗地主接口、WebSocket 和三人匹配
```

## 抽牌比点

### 免登录人机接口

不需要账号，也不写入数据库。`POST /api/test/solo` 开一局，响应里有 `play_id` 和你的手牌。

```bash
POST /api/test/solo
GET  /api/test/solo/{play_id}
POST /api/test/solo/{play_id}/draw
POST /api/test/solo/{play_id}/play
POST /api/test/solo/{play_id}/surrender
```

出牌的请求体：

```json
{"card": "SA"}
```

`SA` 是黑桃 A，`H10` 是红心 10。牌不在手里时，接口返回 400。

### 规则

每人 10 张牌。服务器开局各发 3 张。回合内可以抓 1 张，手牌最多 5 张，然后打出 1 张。双方都出牌后比点数，A 最大，2 最小，花色不计。先到 3 分获胜。轮到你时手里和牌组都空了，判负。投降立刻判负。

## 斗地主

### 免登录人机接口

和比点一样，不需要账号，不写数据库，也不写历史。`POST /api/test/ddz` 开一局。

```bash
POST /api/test/ddz
GET  /api/test/ddz/{play_id}
POST /api/test/ddz/{play_id}/bid        # 叫分，请求体 {"score": 0..3}，0 表示不叫
POST /api/test/ddz/{play_id}/play       # 出牌，请求体 {"cards": ["S3", "H3"]}
POST /api/test/ddz/{play_id}/pass       # 不出
POST /api/test/ddz/{play_id}/advance    # 让机器人走一步
POST /api/test/ddz/{play_id}/hint       # 提示，返回几种能打的牌，不改局面
POST /api/test/ddz/{play_id}/surrender  # 认输
```

牌写法和比点一样，只是多了两张王：`BJ` 是小王，`RJ` 是大王。牌型不合法、压不过上家、还没轮到你，接口都返回 400。

### 机器人出牌是有节拍的

玩家一出完牌，两个机器人不会立刻跟着出完，否则牌桌上什么都看不清。规矩是这样：

- 每次只走一个机器人，走完停一下（叫分停 0.7 秒，出牌停 1.1 秒），网页上能看到它"正在想"。
- 联网的时候服务器自己按这个节拍一步步推局面，网页不用管。
- 免登录的时候没有 WebSocket，网页停一下调一次 `POST /api/test/ddz/{play_id}/advance`，一次只推进一个机器人。局面里带着 `bot_pause`，告诉网页该等多久。
- 现在不是机器人动的时候，`advance` 会把当前局面原样还回来，不改动任何东西。

第一次跑觉得太慢或太快，可以调：

```bash
POKERHUB_BOT_SPEED=0.3 python -m backend.main   # 0.3 倍速；2 就是慢一倍
```

自检里会把它调到 0.05，不然跑一局要等半分钟。

### 记牌器

牌桌上一直显示每个点数还剩几张没露面。算的是"整副牌减去自己手里的、再减去已经打出去的"：别人手里握着的、以及还没被地主拿走的底牌，都算没露面。所以自己是地主时底牌不算，当农民时底牌照样算在里面。

### 打完再来一局

一局结束之后，结算横幅下面有「再来一局」：

- 人机局自己说了算，点了立刻开新的一局。
- 房间匹配要大家都点头。第一个点的人会看到「有人想再来一局（1/3）」，其他人也点了才开新局。

### 规则

一副 54 张，三家各发 17 张，留 3 张底牌。

- **大小**：3 最小，往上到 A，然后 2，最后小王、大王。花色不分大小。
- **叫分**：按座位轮流叫 1 到 3 分，也可以不叫。叫得最高的人当地主，叫到的分就是底分。三家都不叫就重新发牌。
- **地主**拿走 3 张底牌，共 20 张，并且由地主先出牌。
- **牌型**：单张、对子、三张、三带一、三带二、顺子（5 张起）、连对（3 对起）、飞机（2 段起）、四带二、四带两对。顺子、连对、飞机都不能带 2 和大小王。
- **比大小**：牌型和张数都一样才能比，比主牌点数。炸弹（四张一样）压任何普通牌型，王炸（大小王）压炸弹。
- **不出**：压不过就点「不出」。两家都「不出」，由上一手出牌的人重新起头。
- **输赢**：谁先出完手牌，谁那一方赢。地主一个人一方，两个农民一方。
- **算分**：底分 × 倍数。每个炸弹或王炸翻一倍，春天（地主赢且农民一手没出）也翻一倍。地主赢了拿两倍，两个农民各输一份；农民赢了反过来。

机器人是「看得过去」的水平：会按牌型拆牌、跟最小的能压住的牌、不压自己的队友、不轻易动炸弹。它不是最优解。

## 代码从哪读

| 内容 | 文件 |
| --- | --- |
| 比点：发牌、抓牌、合法性、胜负 | `backend/engine.py` |
| 斗地主：牌型、压制、叫分、记牌器、机器人怎么选牌 | `backend/doudizhu.py` |
| 免登录人机接口 | `backend/main.py` 里的 `/api/test/solo` 和 `/api/test/ddz` |
| 注册、匹配、历史、机器人节拍、再来一局 | `backend/main.py` |
| 网页（两个玩法共用一份） | `frontend/app.js`、`frontend/index.html`、`frontend/style.css` |

规则只有一份：网页、WebSocket、自检都调用同一个引擎文件，所以改规则只用改一处。
「机器人该出什么牌」是规则，放在引擎里；「机器人隔多久出一次」是网络层的事，放在 `main.py` 里，两边不混。
